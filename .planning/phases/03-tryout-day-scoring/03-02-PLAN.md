Methods:
- `fetchGroups(seasonId: string)` - Load all groups
- `setActiveGroup(group: TryoutGroup)` - Set the currently active group
- `setActiveStation(stationId: string)` - Set the station being scored
- `fetchScoresForGroupStation(seasonId: string, groupId: string, stationId: string)` - Load existing scores
- `submitScore(seasonId: string, data: CreateStationScoreData)` - Submit score for current player, update stationScores state, show confirmation, then auto-advance after 800ms delay
- `advanceToPlayer(index: number)` - Set activePlayerIndex
- `lookupByBib(bibNumber: number)` - Find player in active group by bib, set activePlayerIndex
- `getPlayerScoreStatus(playerId: string)` - Returns whether player has been scored for active station
- `generateGroups(seasonId: string, data: GenerateGroupsData)` - Generate groups via API
- `addPlayer(groupId: string, data: AddGroupPlayerData)` - Add late-arriving player
- `deleteGroup(groupId: string)` - Delete a group

The auto-advance logic: when `submitScore` succeeds, set `showConfirmation = true`, then after 800ms timeout, set `showConfirmation = false` and advance `activePlayerIndex` to the next unscored player. If all players scored, stay on current player and show a "station complete" state.
