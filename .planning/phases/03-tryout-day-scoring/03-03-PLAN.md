**1. TryoutProgressDashboard.tsx** (`src/components/tryoutScoring/TryoutProgressDashboard.tsx`):

A grid showing group x station completion status with color coding, player-level drill-down, and pull-to-refresh.

Props:
```typescript
{
  seasonId: string;
  template: EvaluationTemplate;
}
```

Implementation:
- Fetch progress data from `api.getTryoutProgress(seasonId)` on mount and on refresh.
- Display as a grid table:
  - Rows: one per group (sorted by rotation_order)
  - Columns: one per station from template.stations
  - Header row: station names
  - First column: group name
  - Each cell: `scoredCount/totalPlayers` text
  - Color coding:
    - Green (`bg-green-100 text-green-800`): complete (scoredCount === totalPlayers)
    - Yellow (`bg-yellow-100 text-yellow-800`): partial (scoredCount > 0 but < totalPlayers)
    - Gray (`bg-gray-100 text-gray-500`): none scored (scoredCount === 0)

- **Player-level drill-down (covers success criterion #5: "which players are missing scores"):**
  - Clicking a progress cell opens a popover or expandable panel showing the individual players for that group-station.
  - For each player: show bib number, name, and scored/missing status icon.
  - Players missing scores should be highlighted (e.g., red text or warning icon) so admin can quickly identify who still needs scoring.
  - The player list is fetched by calling `api.listTryoutGroups(seasonId)` for the group's players, then cross-referencing with `api.listStationScores(seasonId, { groupId, stationId })` to determine which players have been scored.
  - Alternatively, derive this from the progress data if the backend already returns per-player status. If not, fetch on-demand when the cell is clicked.
  - Close button or click-outside to dismiss the drill-down.

- Wrap in `PullToRefresh` from `react-simple-pull-to-refresh`:
  ```tsx
  <PullToRefresh onRefresh={handleRefresh}>
    {/* grid content */}
  </PullToRefresh>
  ```
  The `handleRefresh` function re-fetches progress data and returns a promise.

- Summary stats at top: "Overall: X/Y stations complete" (count of cells where complete=true / total cells).

- Mobile responsive: on narrow screens, make the grid horizontally scrollable (`overflow-x-auto`).

- Also add a regular refresh button (circular arrow icon) for non-mobile users.
