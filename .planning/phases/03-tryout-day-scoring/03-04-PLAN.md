**2. Add cell click handler function:**

When a cell is clicked:
a. Set `selectedCell` to the group/station info
b. Set `cellLoading = true`
c. Fetch group players via `api.listTryoutGroups(seasonId)` -- find the matching group by groupId, extract its `players` array (already has firstName, lastName, bibNumber)
d. Fetch station scores via `api.listStationScores(seasonId, { groupId, stationId })` -- returns StationScore[] for that group-station combo
e. Cross-reference: for each player in the group, check if a StationScore exists with matching `playerId === player.id`
f. Build `cellPlayers` array sorted with missing players first, then scored players, each sub-group sorted by bib number
g. Set `cellLoading = false`

**Important:** The `listTryoutGroups` call returns ALL groups. Cache this data in a ref after first fetch to avoid redundant calls when clicking multiple cells. Use `useRef<TryoutGroup[] | null>(null)` and only fetch if null.

```typescript
const groupsCache = useRef<TryoutGroup[] | null>(null);

const handleCellClick = async (groupId: string, groupName: string, stationId: string, stationName: string) => {
  setSelectedCell({ groupId, groupName, stationId, stationName });
  setCellLoading(true);
  try {
    // Cache groups (contains player lists)
    if (!groupsCache.current) {
      groupsCache.current = await api.listTryoutGroups(seasonId);
    }
    const group = groupsCache.current.find(g => g.id === groupId);
    if (!group) { setCellLoading(false); return; }

    // Fetch scores for this specific group-station
    const scores = await api.listStationScores(seasonId, { groupId, stationId });
    const scoredPlayerIds = new Set(scores.map(s => s.playerId));

    // Build player list with scored status
    const players = group.players.map(p => ({
      bib: p.bibNumber,
      firstName: p.firstName,
      lastName: p.lastName,
      scored: scoredPlayerIds.has(p.id),
    }));

    // Sort: missing first (by bib), then scored (by bib)
    players.sort((a, b) => {
      if (a.scored !== b.scored) return a.scored ? 1 : -1;
      return a.bib - b.bib;
    });

    setCellPlayers(players);
  } catch (err) {
    console.error('Failed to fetch player details:', err);
    setCellPlayers([]);
  } finally {
    setCellLoading(false);
  }
};
```
