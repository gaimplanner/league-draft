`validate_group_player_data(data)` -> (cleaned, errors):
- Required: first_name (str, max 100, stripped), last_name (str, max 100, stripped)
- Optional: bib_number (int, > 0) -- if not provided, auto-assign in the view

`validate_station_score_data(data)` -> (cleaned, errors):

`validate_bulk_scores_data(data)` -> (cleaned, errors):
- Required: station_id (str), scores (list of objects, each with player_id (uuid str) and scores (dict))

**2. Transformers (append to `server/draft/transformers.py`):**

`transform_tryout_group(group, include_players=False)`:
- Returns: id, season_id, name, rotation_order, player_count (group.players.count()), created_at, updated_at
- If include_players=True: include "players" list using transform_group_player

`transform_group_player(player)`:
- Returns: id, group_id, season_id, first_name, last_name, bib_number, created_at

`transform_station_score(score)`:
- Returns: id, season_id, group_id, player_id, station_id, scores, scored_by_id (str), scored_by_email (score.scored_by.email), scored_at, updated_at

`transform_tryout_progress(groups, stations, scores_by_group_station)`:
- Returns list of objects: group_id, group_name, station_id, station_name, scored_count, total_players, complete (bool)

**3. Views (`server/draft/views/tryout_scoring.py`):**

Follow the exact pattern from `coach_ratings.py`: decorators (@require_http_methods, @csrf_protect, @require_auth), get organization from request, verify membership role, etc.

Endpoints:

a) `tryout_groups_list_create(request, season_id)` - GET/POST
   - GET: List all groups for a season (admin only). Return with include_players=True.
   - POST: Create a group. Admin only. Validate with validate_tryout_group_data.

b) `tryout_group_detail(request, pk)` - GET/PATCH/DELETE
   - Standard detail view for a group. Admin only.
   - GET returns group with players.
   - PATCH updates name and/or rotation_order.
   - DELETE removes group and cascades.

c) `tryout_group_generate(request, season_id)` - POST
   - Admin only. Auto-generates groups from a list of players.
   - Request body: `{ players: [{ first_name, last_name }], group_size?: number }` -- group_size defaults to 18.
   - Algorithm: sort players by last_name, split into groups of group_size. Name groups "Group 1", "Group 2", etc.
   - Auto-assign bib numbers sequentially starting from 1 across all groups.
   - Create TryoutGroup and GroupPlayer records in a transaction.
   - Return created groups with players.

d) `tryout_group_add_player(request, pk)` - POST
   - Admin only. Add a late-arriving player to an existing group.
   - Request body: `{ first_name, last_name }`.
   - Auto-assign next bib number (max bib in season + 1).
   - Create GroupPlayer record.

e) `tryout_station_scores(request, season_id)` - GET/POST
   - GET: List station scores for a season, with optional query params: group_id, station_id, player_id for filtering.
   - POST: Create or update a single station score (used by mobile scoring UI).
     - Body: `{ player_id, station_id, scores }`.
     - If a StationScore already exists for this player+station, update it (upsert pattern using update_or_create).
     - Set scored_by to request.user.
     - Coach or admin role required.

f) `tryout_station_score_detail(request, pk)` - GET/PATCH/DELETE
   - Standard detail view for a station score. Coach or admin.

g) `tryout_bulk_scores(request, season_id)` - POST
   - Admin only. Bulk create/update station scores for a station.
   - Body: `{ station_id, scores: [{ player_id, scores: {...} }] }`.
   - For each entry, use update_or_create keyed on (season, player, station_id).
   - Wrap in transaction.atomic().
   - Return count of created/updated records.

h) `tryout_progress(request, season_id)` - GET
   - Admin only. Return tryout progress grid.
   - Get all groups for the season.
   - Get station definitions from season.template.stations.
   - For each group, count station scores per station.
   - Return using transform_tryout_progress.
   - Use prefetch_related('scores', 'players') to avoid N+1 queries.
