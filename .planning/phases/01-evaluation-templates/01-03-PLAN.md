**Create src/components/evaluation/templatePresets.ts:**

Define a `STANDARD_TRYOUT_PRESET` constant with the standard Little League evaluation template data (used as a starting point when admin clicks "Start from preset"):

Stations:
1. **Infield** (order: 1): Fields: "Ground Balls" (count, 0-3, description: "Successful ground ball fielding out of 3"), "Throw Accuracy" (scale, 1-5, anchors: 1="Cannot throw to base", 3="Average throw, reaches base", 5="Strong, accurate throw consistently")
2. **Base Running** (order: 2): Fields: "120ft Sprint" (time, 0-30, unit: "seconds", lowerIsBetter: true, description: "Time to run 2x60ft (home to second)")
3. **Fly Balls** (order: 3): Fields: "Catches" (count, 0-3, description: "Successful fly ball catches out of 3")
4. **Pitching** (order: 4): Fields: "Accuracy" (scale, 1-5, anchors: 1="Cannot find the strike zone", 3="Some strikes, inconsistent", 5="Consistently hits target"), "Form" (scale, 1-5, anchors: 1="No recognizable form", 3="Basic mechanics present", 5="Excellent mechanics, repeatable motion")
5. **Hitting** (order: 5): Fields: "Contact" (count, 0-5, description: "Solid contact out of 5 machine pitches"), "Power" (scale, 1-5, anchors: 1="No power, taps only", 3="Moderate power, reaches outfield grass", 5="Strong power, clears outfield")

Coach Categories:
Physical: "Fielding", "Hitting", "Running", "Pitching", "Catching" (all scale 1-5 with standard anchors: 1="Below expectations", 2="Needs improvement", 3="Meets expectations", 4="Above expectations", 5="Exceptional")
Soft: "Baseball IQ" (anchors: 1="Does not understand game situations", 3="Good awareness", 5="Anticipates plays, makes smart decisions"), "Hustle" (1="Low effort", 3="Consistent effort", 5="Maximum effort every play"), "Coachability" (1="Resistant to instruction", 3="Accepts feedback", 5="Actively seeks and applies feedback")

Blend Weights: { coachRating: 40, tryoutScore: 60 }

Every station, field, and category MUST have a UUID `id` generated with `crypto.randomUUID()`. Export a function `getStandardPreset(): CreateTemplateData` that generates fresh UUIDs each time (do NOT use static UUIDs -- they must be unique per template instance).

**Create src/components/evaluation/BlendWeightsEditor.tsx:**

A linked slider component:
- Two range inputs: "Coach Rating" and "Tryout Score"
- When one changes, the other automatically adjusts so they sum to 100 (see-saw behavior)
- Display both percentages prominently (e.g. "40%" / "60%")
- Use react-hook-form's `useFormContext` to read/write `blendWeights.coachRating` and `blendWeights.tryoutScore`
- Show validation error from zod if weights don't sum to 100 (edge case protection)
- Use `Controller` from react-hook-form for range inputs

**Create src/components/evaluation/ScoreFieldEditor.tsx:**

Component for editing a single score field within a station:
- Props: `nestIndex` (station index), `fieldIndex` (field index within station), `onRemove` callback
- Uses `useFormContext` to access form state at `stations.{nestIndex}.fields.{fieldIndex}`
- Fields: name (text input), type (select: scale/time/count), min (number), max (number), description (textarea, optional)
- Conditional fields based on type:
  - scale: Show anchors editor (key-value pairs for each level from min to max, e.g. "1: Poor", "5: Excellent"). Pre-fill anchor keys based on min/max. Each anchor value is a text input.
  - time: Show unit input (default "seconds"), show lowerIsBetter checkbox (default true)
  - count: No extra fields needed
- Remove button (trash icon) that calls onRemove
- Show validation errors from zod inline (red text under invalid fields)
- Compact layout: fields on one or two rows, anchors expand below when type is "scale"

**Create src/components/evaluation/StationEditor.tsx:**

Component for editing a single station with its nested score fields:
- Props: `stationIndex` (position in stations array), `onRemove` callback, `onMoveUp`/`onMoveDown` callbacks
- Uses `useFormContext` to access `stations.{stationIndex}`
- Uses `useFieldArray` from react-hook-form with `name: \`stations.${stationIndex}.fields\`` to manage the nested score fields array
- Station header: name text input, drag handle or up/down buttons, remove button
- Lists ScoreFieldEditor for each field in the station
- "Add Score Field" button that appends a new field with `{ id: crypto.randomUUID(), name: '', type: 'scale', min: 1, max: 5 }`
- Show validation errors for station name and "at least one field required"
- CRITICAL: Use `field.id` from useFieldArray as the React `key` prop, NOT the array index. This prevents form state corruption on reorder/remove.

**Create src/components/evaluation/CoachCategoryEditor.tsx:**

Component for the entire coach categories section:
- Uses `useFieldArray` with `name: 'coachCategories'` for the categories array
- Each category card shows: name input, type toggle (physical/soft badge buttons), min/max (default 1-5, likely fixed for coach categories)
- Anchors editor: for each level 1-5, a text input for the anchor description. Pre-fill common anchors based on type (physical gets generic sports anchors, soft gets behavioral anchors)
- "Add Physical Skill" and "Add Soft Skill" buttons that append with appropriate defaults and fresh UUID
- Remove button per category
- CRITICAL: Use `field.id` from useFieldArray as React `key`, not index

**Create src/components/evaluation/TemplateEditor.tsx:**

Main template editor form, the orchestrator component:
- Props: `existingTemplate?: EvaluationTemplate`, `onSave: (template: EvaluationTemplate) => void`, `onCancel: () => void`
- Uses `useForm` with `zodResolver(templateFormSchema)` and defaultValues from existingTemplate or empty template
- Uses `useFieldArray` with `name: 'stations'` for the stations array
- Layout sections (vertical, scrollable):
  1. **Header**: Template name input + description textarea. If editing a locked template, show info banner: "This template has been used for scoring. Saving will create a new version."
  2. **Preset button**: If creating new (no existingTemplate), show "Start from Standard Little League preset" button that calls `reset()` with preset data from `getStandardPreset()`
  3. **Tryout Stations section**: List of StationEditor components. "Add Station" button appends `{ id: crypto.randomUUID(), name: '', order: stations.length + 1, fields: [{ id: crypto.randomUUID(), name: '', type: 'scale', min: 1, max: 5 }] }`. Move up/down uses `useFieldArray.move()`.
  4. **Coach Review Categories section**: CoachCategoryEditor component
  5. **Blend Weights section**: BlendWeightsEditor component
  6. **Footer**: Cancel button + Save button. Save calls `handleSubmit` which calls `onSave` with form data
- On submit: Call `createTemplate` or `updateTemplate` from useEvaluationTemplates hook depending on whether existingTemplate exists. Pass the form data. On success, call `onSave` with the returned template.
- Show form-level errors (from zod validation) at the top of the form
- CRITICAL: All useFieldArray items must use `field.id` as React key

Style with Tailwind: white background card, subtle borders between sections, consistent spacing (space-y-6 between sections, space-y-4 within), consistent input styling (matching existing app inputs).
