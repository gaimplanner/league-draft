**Models (add to bottom of server/draft/models.py):**

Add `EvaluationTemplate` model:
- `id` = UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
- `organization` = ForeignKey(Organization, on_delete=CASCADE, related_name='evaluation_templates')
- `name` = CharField(max_length=200)
- `description` = TextField(blank=True, default='')
- `version` = IntegerField(default=1)
- `parent_template` = ForeignKey('self', on_delete=SET_NULL, null=True, blank=True, related_name='child_versions')
- `stations` = JSONField(default=list) -- array of station objects, each with id, name, order, fields[]
- `coach_categories` = JSONField(default=list) -- array of category objects, each with id, name, type (physical/soft), min, max, anchors
- `blend_weights` = JSONField(default=dict) -- { "coachRating": 40, "tryoutScore": 60 }
- `is_active` = BooleanField(default=True)
- `is_locked` = BooleanField(default=False) -- set True when scores reference this version
- `created_by` = ForeignKey(User, on_delete=SET_NULL, null=True, blank=True)
- `created_at` = DateTimeField(auto_now_add=True)
- `updated_at` = DateTimeField(auto_now=True)
- Meta: db_table="evaluation_templates", ordering=["-updated_at"], UniqueConstraint on fields=['organization', 'name', 'version'] named 'unique_template_version'
- __str__ returns f"{self.name} v{self.version}"

Add `Season` model:
- `id` = UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
- `organization` = ForeignKey(Organization, on_delete=CASCADE, related_name='seasons')
- `name` = CharField(max_length=100) -- e.g. "Spring 2026"
- `year` = IntegerField()
- `template` = ForeignKey(EvaluationTemplate, on_delete=PROTECT, related_name='seasons') -- PROTECT prevents deleting used templates
- `is_active` = BooleanField(default=True)
- `created_at` = DateTimeField(auto_now_add=True)
- `updated_at` = DateTimeField(auto_now=True)
- Meta: db_table="seasons", ordering=["-year", "-created_at"], UniqueConstraint on fields=['organization', 'name'] named 'unique_season_name_per_org'
- __str__ returns self.name

**Create server/draft/views/evaluation_templates.py:**

Follow the exact pattern from `server/draft/views/divisions.py` (decorator stack, parse body, validate, business logic, transform response).

`evaluation_templates_list_create(request)`:
- Decorators: @require_http_methods(["GET", "POST"]), @csrf_protect, @require_auth
- GET: Filter `EvaluationTemplate.objects.filter(organization=organization, is_active=True).order_by('-updated_at')`. Return 200 with list of transformed templates. If no organization context, return 400 "No organization context".
- POST: Parse body, validate with `validate_template_create_data`, create template with `organization=organization, created_by=request.user, **cleaned`. Return 201 with transformed template.

`evaluation_template_detail(request, pk)`:
- Decorators: @require_http_methods(["GET", "PATCH", "DELETE"]), @csrf_protect, @require_auth
- Get template by pk, verify `template.organization == organization` (return 404 if not found or wrong org).
- GET: Return 200 with transformed template.
- PATCH: Parse body, validate with `validate_template_update_data`. **Versioning logic:** If `template.is_locked` is True, create a NEW template row: copy all fields from existing template, apply updates from cleaned data, set `version = template.version + 1`, set `parent_template = template`, set `created_by = request.user`, set `is_active = True`. Then deactivate the old template (`is_active = False`, save). Return 201 with transformed NEW template. If `template.is_locked` is False, update in place and return 200.
- DELETE: Soft delete by setting `is_active = False`. Return 204 (no content). Do NOT hard delete because child versions may reference it as parent. If template `is_locked`, return 400 "Cannot delete a template that has been used for scoring. Create a new version instead."

**Create server/draft/views/seasons.py:**

`seasons_list_create(request)`:
- Decorators: @require_http_methods(["GET", "POST"]), @csrf_protect, @require_auth
- GET: Filter `Season.objects.filter(organization=organization).order_by('-year', '-created_at')`. Return 200 with list of transformed seasons.
- POST: Parse body, validate with `validate_season_create_data`. Look up template by `template_id`, verify it belongs to same organization. Create season. Return 201.

`season_detail(request, pk)`:
- Decorators: @require_http_methods(["GET", "PATCH", "DELETE"]), @csrf_protect, @require_auth
- GET: Return 200 with transformed season.
- PATCH: Validate with `validate_season_update_data`. If `template_id` is being changed, verify new template exists and belongs to org. Update and return 200.
- DELETE: Hard delete (seasons themselves are lightweight). Return 204.
