# Design Context

## Users

Little League volunteer admins and coaches running live in-person drafts. Primary viewing context is **desktop**, often projected onto a TV or screen while 6–12 coaches stand around a table arguing picks. Draft night typically runs 60–120 minutes under time pressure, with the admin clicking through 80–150 picks in one sitting.

Secondary viewing: the admin reviewing rosters, setup, and exports on the same desktop between draft sessions. Mobile/tablet is NOT a supported context — we optimize for dense desktop use.

The job-to-be-done: **run a draft in a room full of people without losing your place, making the wrong pick, or looking like an unprepared volunteer.** Stakes are social, not financial — a wrong click in front of a room of coaches is embarrassing.

## Brand Personality

Three words: **confident, numeric, unhurried.**

The feel is a well-produced **press-box scorecard** — precise, data-dense, quietly authoritative. Not ESPN-hype (no gradient tickers, no celebratory emoji showers). Not sterile admin-SaaS (no generic Tailwind rounded-card-and-shadow). The in-between: a scoreboard voice that takes the data seriously.

**Emotional goal**: the admin feels in control; the coaches in the room feel like they're watching something legitimate, not a spreadsheet.

## Aesthetic Direction

**Visual tone**: refined sports broadcast. Big numbers, tight alignment, one dominant accent color, generous negative space around the moment that matters (the current pick).

**Theme**: **Light default**, with a distinct high-contrast "presentation mode" for projectors (activated via the existing scores-visibility toggle or a dedicated projector toggle).

**Anti-references** (explicitly NOT this):
- ESPN Bottomline hype: no gradient banners, no scrolling tickers, no animated celebrations
- Generic Tailwind admin: no rounded-lg + border-gray + shadow-lg on every surface
- Emoji-as-design: no 🎉 / 🏆 / 📊 / 🐍 / ⭐ as primary visual elements in chrome
- Rainbow semantic palette: no simultaneous blue + green + yellow + red + purple + orange

**Positive references** (lean into this): classic baseball scorecards, the numeric precision of The Economist's sports pages, the tight grid discipline of a trading-terminal dashboard with sports-media warmth.

### Typography

- **Display / numeric / structural**: **Archivo** (Omnibus-Type, Google Fonts). Black (900) for score callouts and current-pick names; SemiBold (600) for team names; Regular (400) for body labels. Tabular figures always on for columns of numbers. Chosen because it has genuine scoreboard weight at 900 without being overused (not in the reflex font list), and its tabular figures handle the data-heavy tables cleanly.
- **Mono / data cells / BIB / tabular numerics**: **Azeret Mono** (Displaay, Google Fonts). Squared, mechanical, reads as "official scoreboard digits" rather than "developer terminal." Used sparingly — BIB numbers, score cells, pick numbers.
- **Bans**: Inter, DM Sans, IBM Plex, Space Grotesk, Roboto Mono, JetBrains Mono, and the rest of the reflex list.

### Color

All OKLCH. Neutrals tinted subtly toward the brand hue (150°, green).

- `--brand`: `oklch(48% 0.12 150)` — deep athletic green, the single dominant accent. Used only for: current pick, primary CTA, locked-to-own-team indicator.
- `--surface`: `oklch(98.5% 0.005 150)` — off-white, barely tinted green
- `--surface-2`: `oklch(95% 0.008 150)` — panel background
- `--ink`: `oklch(20% 0.01 150)` — body text
- `--ink-muted`: `oklch(50% 0.01 150)` — secondary text, axis labels
- `--rule`: `oklch(90% 0.005 150)` — hairline borders (1px only)
- `--alert`: `oklch(56% 0.19 25)` — warm red, used ONLY for mandatory picks and locked-to-other-team (genuine urgency, rare)
- `--warn`: `oklch(72% 0.14 80)` — amber, used ONLY for age-limit warnings
- Dark mode: `--surface` becomes `oklch(16% 0.01 150)`, ink inverts, brand shifts to `oklch(62% 0.11 150)` for contrast

**No sibling-purple, no DNE-orange as distinct hues.** Sibling/DNE/coach-kid become monochrome letter-glyphs (SIB, DNE, CK) in muted ink — meaning comes from the letters, not the color.

### Spacing & Surfaces

- 4px scale with semantic tokens: `--space-1` (4), `--space-2` (8), `--space-3` (12), `--space-4` (16), `--space-6` (24), `--space-8` (32), `--space-12` (48)
- **No rounded-lg everywhere.** Sharp 2px corners for data surfaces (tables, panels). 4px only for interactive buttons. Zero corner radius on structural dividers.
- **No nested cards.** One container depth max.
- **1px hairline borders** in `--rule`; no drop shadows except on true floating layers (modals).

## Design Principles

1. **The current pick is the hero.** The name of the team picking RIGHT NOW is the largest type on the page, every time. Everything else demotes.
2. **One accent, used rarely.** Green means "action happening now." If everything is green, nothing is. Alerts (red) and warnings (amber) appear only when truly warranted.
3. **Numbers are typography.** Scores, BIBs, pick counts, ranks — these are first-class design elements. Tabular figures, precise alignment, restraint on color so the digits carry the weight.
4. **Silent when nothing is wrong.** No cheerful 🎉, no celebratory modal theater. A completed round just updates the order and carries on. Celebration is reserved for the very end.
5. **Consistency beats decoration.** One confirm pattern, one modal chrome, one empty-state voice. A coach sees the same interaction shape every time.
